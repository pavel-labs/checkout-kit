## Установка из npm

```sh
npm install @checkout-kit/core @checkout-kit/runtime-browser @checkout-kit/provider-paypal
```

Выполните команду в своём приложении. Все 16 пакетов опубликованы в публичном npm; токен и приватный реестр не нужны. В [каталоге](./packages.md) — ссылки на каждый пакет, в [быстром старте](./getting-started.md#install-from-npm) — установка для Stripe, Adyen, React, UI, WebView и тестирования.

## Начните с рабочего примера

```sh
npm ci
npm run dev:integration
```

Запустите это в [репозитории](https://github.com/pavel-labs/checkout-kit). Откроется React-страница оплаты и тестовый сервер с поддельными провайдерами — ключи аккаунтов не нужны. Дальше [быстрый старт](./getting-started.md) объясняет, как установить пакеты и подключить настоящий тестовый аккаунт.

## Кто за что отвечает

Движок создаёт платёж, передаёт платёжные данные, выполняет дополнительные шаги (например, страницу 3-D Secure от банка) и затем проверяет результат.

- **Плагин провайдера** знает, как общаться с конкретным провайдером.
- **Раннер** показывает дополнительный шаг в вашем приложении (фрейм, перенаправление, SDK).
- **Ваш сервер** знает цены, знает покупателя и решает, оплачен ли заказ.

Во всех 16 пакетах есть JavaScript (ESM), типы TypeScript, документация API и тесты. Пакеты-примеры показывают типовые протоколы, но не сертифицированы ни для одного настоящего банка. Все пакеты доступны в npm. Для своей интеграции по-прежнему нужна проверка на собственном тестовом аккаунте провайдера. В разделе [сервер мерчанта](./merchant-integration.md) перечислено, что должен делать ваш сервер. [Решение проблем](./troubleshooting.md) поможет, если что-то не работает.
