# Каталог пакетов

> [English](../packages.md)

Checkout kit разбит на 16 отдельных пакетов, поэтому ставить нужно только то, что используете. Обычному веб-приложению нужны:

- `core` — платёжный движок (нужен всегда);
- один пакет провайдера, например `provider-stripe`;
- `runtime-browser` — чтобы движок работал в браузере;
- `react` — если приложение на React 19;
- `ui` — если нужны готовые компоненты (необязательно).

Все 16 пакетов опубликованы в публичном npm. В каждом есть JavaScript (ESM), типы TypeScript и экспорты; установка проверяется в отдельном чистом проекте. Версии независимы: в таблицах ниже указаны опубликованные версии. Команда `npm view @checkout-kit/core version` (или имя другого пакета) покажет текущую версию `latest`.

## Адаптеры конкретных провайдеров {#named-provider-adapters}

Эти три пакета работают с настоящими провайдерами. Браузер обращается к **вашему** серверу, а сервер — к провайдеру. К каждому есть пример ввода данных карты через SDK провайдера, рабочий сервер, тестовые данные и браузерные тесты. Проверить всё на своём тестовом аккаунте (песочнице) всё равно нужно самостоятельно.

| Пакет / id                                                                                                | Версия  | Чем платит покупатель и как проходит оплата                                                                                                                    | Руководство                     |
| --------------------------------------------------------------------------------------------------------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| [`@checkout-kit/provider-stripe`](https://www.npmjs.com/package/@checkout-kit/provider-stripe) / `stripe` | `0.1.1` | Токен PaymentMethod из Stripe.js. Используются PaymentIntents, шаги SDK и перенаправления. Деньги списываются автоматически.                                   | [Stripe](./providers/stripe.md) |
| [`@checkout-kit/provider-adyen`](https://www.npmjs.com/package/@checkout-kit/provider-adyen) / `adyen`    | `0.2.0` | Зашифрованные данные из компонента Adyen, токен сохранённой карты или данные карты напрямую, если вы это разрешили. Advanced flow; состояние проверяет сервер. | [Adyen](./providers/adyen.md)   |
| [`@checkout-kit/provider-paypal`](https://www.npmjs.com/package/@checkout-kit/provider-paypal) / `paypal` | `0.1.1` | На вашей странице ничего не вводится. Покупатель подтверждает оплату в PayPal (Orders v2), потом ваш сервер списывает и проверяет платёж.                      | [PayPal](./providers/paypal.md) |

Названия всех пакетов начинаются с `@checkout-kit/`.

## Установка и зоны ответственности {#installation-and-support-boundary}

В [быстром старте](./getting-started.md#install-from-npm) есть готовые команды для каждого варианта, всех протоколов-примеров и обоих пакетов для разработки. Ставьте указанные выше имена со scope из npm: авторизация GitHub Packages и установщик архивов не нужны. Архивы GitHub остаются альтернативой для старых комплектов и сборок из исходников.

**Библиотека** проводит оплату на стороне клиента: шаги, повторы, восстановление.

**Ваш сервер** отвечает за:

- вход покупателя;
- цены;
- секретные ключи;
- хранение заказов в базе данных;
- то, что каждая операция выполняется только один раз (идемпотентность), даже при параллельных запросах;
- проверку уведомлений провайдера (вебхуков);
- выдачу заказа.

Подробнее — в разделе [сервер мерчанта](./merchant-integration.md).
